Mixed Theme

用 coldFrom / warmFrom 从 5 个 builtin 主题自由拼色 · 2^5 = 25 种组合

// 用法 1: 顶层 coldFrom / warmFrom 字段(推荐)
matrixRain({ coldFrom: 'cyber-blue', warmFrom: 'lava-red' });

// 用法 2: theme 对象写法
matrixRain({ theme: { coldFrom: 'matrix-green', warmFrom: 'silicon-valley' } });

// 拼色后,setTheme('matrix-green') 会切回纯色,丢拼色信息
