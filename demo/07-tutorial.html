INSTALL · 安装

3 种安装方式

支持所有现代包管理器,也支持 CDN 单文件。

STEP 01

npm

$ npm install @xietuier/matrix-rain
STEP 02

pnpm / yarn

$ pnpm add @xietuier/matrix-rain
$ yarn add @xietuier/matrix-rain
STEP 03

CDN (无需 npm)

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@xietuier/matrix-rain/dist/matrix-rain.css">
<script type="module">
  import { matrixRain } from '@xietuier/matrix-rain';
  matrixRain({ theme: 'silicon-valley' });
</script>
QUICKSTART · 5 分钟上手

一行代码起手

默认配置即可用。需要深度定制时,所有参数都是可选项。

STEP 01

最小可用

import { matrixRain } from '@xietuier/matrix-rain';

const rain = matrixRain(); // 默认 硅 谷风 + 经典变体

// 用完销毁(推荐 SPA 路由切换时调)
rain.destroy();
STEP 02

带样式

import { matrixRain } from '@xietuier/matrix-rain';
import '@xietuier/matrix-rain/style.css'; // 5 层暗色背景

const rain = matrixRain({
  theme: 'silicon-valley',
  fontSize: 14,
});
STEP 03

深度定制

const rain = matrixRain({
  theme: 'silicon-valley',
  variant: 'avalanche',        // 雪崩下落
  charset: '01+-',                  // 自定义字符集
  trailAlpha: 0.12,                  // 拖尾更长
  lightCenter: { x: 0.5, y: 0.5 },   // 光心居中
  warmthLerp: 0.1,                    // 暖色更紧跟
});

INTEGRATION · React

React 组件

用 useEffect 接管生命周期,组件卸载时自动 destroy。

基础用法
import { useEffect } from 'react';
import { matrixRain } from '@xietuier/matrix-rain';
import '@xietuier/matrix-rain/style.css';

export function MatrixRain({ theme = 'silicon-valley' }) {
  useEffect(() => {
    const rain = matrixRain({ theme });
    return () => rain.destroy(); // 卸载时销毁
  }, [theme]);

  return null; // Canvas 由库自动创建
}
进阶:动态主题切换
import { useEffect, useRef } from 'react';
import { matrixRain, type MatrixRainInstance } from '@xietuier/matrix-rain';

export function MatrixRain({ theme }) {
  const ref = useRef<MatrixRainInstance>(null);

  useEffect(() => {
    ref.current = matrixRain({ theme });
    return () => ref.current?.destroy();
  }, []);

  useEffect(() => {
    ref.current?.setTheme(theme); // 主题 prop 变了不重建,只换色
  }, [theme]);

  return null;
}
INTEGRATION · Vue 3

Vue 3 组件

onMounted / onUnmounted / watch 三件套。

基础用法
<script setup>
import { onMounted, onUnmounted, ref, watch } from 'vue';
import { matrixRain } from '@xietuier/matrix-rain';
import '@xietuier/matrix-rain/style.css';

const props = defineProps({ theme: { type: String, default: 'silicon-valley' } });
const instance = ref(null);

onMounted(() => { instance.value = matrixRain({ theme: props.theme }); });
onUnmounted(() => instance.value?.destroy());
watch(() => props.theme, t => instance.value?.setTheme(t));
</script>

<template><!-- 不需要任何 DOM --></template>
