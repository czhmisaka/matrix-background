## 5. 修复明细

按 P0 → P1 → P2 列出所有触达的 issues。每项给出:**症状 · 命中位置 · 修复方案 · 改动文件**。

### 5.1 P0(必须修,影响键盘 + 屏幕阅读器 + critical axe)

#### P0-1 · Skip-to-content 链接缺失
- **症状**:键盘用户 Tab 进入页面后,必须穿过完整 NavBar 才能到达主要内容,长导航时浪费焦点跳转。
- **命中**:`/`、`/demos`、`/tutorial`、`/playground`、`/blog`、`/docs`、`/legacy` 等所有路由。
- **修复**:在 `<App>` 顶部插入 `<a href="#main" class="skip-link">跳到主要内容</a>`,
  并给 `<main>` 加 `id="main" tabindex="-1"`。视觉上默认 `position: absolute; left: -9999px`,
  `:focus` 时滑入屏幕。
- **改动**:`App.vue`,`style.css`(全局)。

#### P0-2 · Hero / 装饰 canvas 缺少 `aria-hidden="true"`
- **症状**:屏幕阅读器把 canvas 当成"图形"内容区,无 alt 也无 innerText,可能报"无标签图形"。
- **命中**:`HeroCanvas.vue`(首页),`NotFoundPage.vue`(`BackgroundMatrixRain`),
  `PlaygroundPage.vue`、各 demo 页的装饰 canvas。
- **修复**:在 `<canvas>` 上加 `aria-hidden="true"`;若 canvas 是信息载体(罕见),改用 `<figure>` + `<figcaption>`。
- **改动**:`HeroCanvas.vue`、各处装饰性 canvas 容器。

#### P0-3 · 滑块 `<input type="range">` 缺 label / `aria-label`
- **症状**(critical axe):3 个滑块没有可访问名(Playground 4-7 个、DemoNoiseConverge 3 个),屏幕阅读器朗读 "input, range, 0-3, value 0"。
- **命中**:`/playground`(fontSize / trailAlpha / maxDPR / brightness / targetNoiseDuration / targetConvergeDuration / targetLockStability),
  `/demos/noise-converge`(3 个)。
- **修复**:两种方案任选,采用 **方案 B**(更稳):
  - 方案 A:把 `<input>` 包在 `<label>` 里,删除独立 span("Font Size")。
  - 方案 B:在 `<input>` 上加 `aria-label="Font Size"`、`aria-valuemin`、`aria-valuemax`、
    `aria-valuenow`(动态绑定) + `aria-valuetext`(用 `cv` span 的值,带单位 px / s)。
- **改动**:`PlaygroundPage.vue`、读 `DemoNoiseConverge.vue` 修复同类问题。

#### P0-4 · 阶段指示 pill 缺 `role="status"` + `aria-live="polite"`
- **症状**:屏幕阅读器在 phase 从 `idle → noise → converge → hold` 切换时不会播报,
  视障用户失去"涌现动画当前在哪一阶段"的信息。
- **命中**:`/playground` 右上角两个 pill(phase / elapsed)。
- **修复**:`<span class="info-pill" role="status" aria-live="polite">`。
- **改动**:`PlaygroundPage.vue`。

#### P0-5 · NavBar 当前路由缺 `aria-current="page"`
- **症状**:屏幕阅读器用户无法快速识别"我现在在哪一页"。视觉用户有 `router-link-active` 下划线提示,
  视障用户没有等价信息。
- **命中**:`NavBar.vue` 5 个 RouterLink。
- **修复**:`<RouterLink :aria-current="isActive ? 'page' : undefined">`。
  用 `useRoute()` 计算,或者直接利用 Vue Router 自动加的 `.router-link-active` class 做 wrapper。
- **改动**:`NavBar.vue`。

#### P0-6 · DemoCard 装饰性 clickable `<div>` 缺 role + keyboard
- **症状**:HomePage `strip-cell` div 是真按钮(切主题),但没有 `role="button"` / `tabindex="0"`,
  不能用 Enter / Space 触发。
- **命中**:`HomePage.vue` `themes-strip` 5 个 `.strip-cell`。
- **修复**:把 `<div class="strip-cell">` 改成 `<button type="button" class="strip-cell">`,
  样式稍作调整(去除 button 默认 `border`/`background`/`padding`)。
- **改动**:`HomePage.vue`。

#### P0-7 · Blog `post-header` clickable 缺 keyboard
- **症状**:Blog 文章折叠/展开是 `@click` 在 `<header>` 上,键盘用户无法操作。
- **命中**:`BlogPage.vue` `.post-header`。
- **修复**:包一层 `<button>` 覆盖整个 header,或把 header 改成 `<button class="post-header">`。
- **改动**:`BlogPage.vue`。

#### P0-8 · `:focus-visible` 样式缺失
- **症状**:键盘用户 Tab 聚焦时,默认浏览器 outline 可能在某些 element 上被 `outline: none` 覆盖。
- **命中**:`style.css` line 285 显式 `outline: none` 在 input/select/textarea 上。
- **修复**:保留 `outline: none` 但加 `:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }`。
  全局 `*:focus-visible` 兜底(避免遗漏),并对 `input/select/textarea/button/a` 显式加强。
- **改动**:`style.css`。

#### P0-9 · NavBar `<nav>` 加 `aria-label` 区分主/页脚
- **症状**(landmark-unique axe):两个 `<nav>`(NavBar + Docs side nav) 同 role 但都没 label,
  axe 报 "Landmarks should have a unique role or role/label/title"。
- **命中**:`NavBar.vue`、`DocsPage.vue` `side-nav`。
- **修复**:`<nav class="nav-links" aria-label="主导航">` 和 `<nav class="side-nav" aria-label="本页章节">`。
- **改动**:`NavBar.vue`、`DocsPage.vue`。

#### P0-10 · `prefers-reduced-motion: reduce` 不支持
- **症状**:前庭功能障碍用户在 macOS / iOS 启用"减少动态效果"后,本站在
  - 8s 涌现循环
  - 状态机 4 段动画
  - pulse 2s 呼吸
  - nav-links max-height 240ms 过渡
  全部会播放。前庭易感用户可能眩晕。
- **修复**:全局加
  ```css
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation-duration: 0.01ms !important;
      animation-iteration-count: 1 !important;
      transition-duration: 0.01ms !important;
    }
  }
  ```
  另外 HeroCanvas 监听 `prefers-reduced-motion`,为 `reduce` 时**不**启动 8s 循环,
  只做一次涌现后停在 hold 阶段。
- **改动**:`style.css`、`HeroCanvas.vue`。

> 上面 10 条为 P0 必修。下一节 P1 是"应该修"。

### 5.2 P1(应该修,主要颜色对比)

#### P1-1 · `--text-faint` (#3b3e54) on `--bg` (#0a0a14) 失败
- **症状**:对比比 ≈ 2.2:1,远低于 WCAG AA 要求 4.5:1(正文)/ 3:1(大字号)。
- **命中**(axe 118 处):
  - `FooterBar.vue` `.footer-col h5`("Explore / Reference / Resources")
  - `FooterBar.vue` `.footer-bottom`(© 2026 · 本地部署)
  - `BlogPage.vue` `.post-meta`、`.post-tag`、`.post-toggle`
  - `PlaygroundPage.vue` `.params h3`(基础参数 / Target · 涌现 / Target · 文本)
  - `PlaygroundPage.vue` `.hint`
  - `HeroCanvas.vue` `.hero-meta`(noise-converge 涌现 · 本地部署 · MIT)
  - `TutorialPage.vue` `.tab-content` 表格 th
  - `DocsPage.vue` `.api-table` th
  - `HomePage.vue` `.feature-num` 不是(它用 accent)
  - 各处 `.eyebrow` 边框 / `.tag` 边框也涉及
- **修复**:`--text-faint` 从 `#3b3e54` 改为 `#5a5d75`(实际就是 `--text-dim`),
  或者新增 `--text-faint-2: #5a5d75` 保留视觉差。但 `#5a5d75` 单独算 = 3.6:1,仍不达 AA。
  **真正解法**:`--text-faint` 升到 `#6b6f8a`(~ 4.7:1,过 AA)。
  调色板同步更新 `tk-com`(#5a5d75 → #6b6f8a)。
- **改动**:`style.css`、所有引用 `var(--text-faint)` 的 vue 组件。

#### P1-2 · `.tk-com` (#5a5d75) on `--bg` 失败
- **症状**:3.6:1,在代码块 pre 背景 `#11111e` 上更糟(3.1:1)。
- **命中**:`DemoElement.vue`、所有 `<pre><code>` 内的注释文字、`DocsPage.vue` 32 处。
- **修复**:`.tk-com` 改为 `#7a7d95`(对比 ~ 4.7:1)。注释语义上确实应该是 low-prominence,
  改色后视觉仍然 muted。
- **改动**:`style.css`。

#### P1-3 · `--text-dim` (#5a5d75) on `--bg` 失败
- **症状**:3.6:1,同上。
- **命中**:少数页面有引用(`style.css` 定义但未在 vue 组件中显式使用,fallthrough)。
- **修复**:`--text-dim: #6b6f8a`。
- **改动**:`style.css`。

#### P1-4 · DemosPage "Try it →" 链接
- **症状**:`.demo-card-cta` 继承 `.footer-col a` 的 `--text-muted`,在 card 背景上对比足够
  (8.5:1),但 hover 时无下划线,纯靠颜色变化。
- **修复**:保留 hover 颜色变化,加 `text-decoration: underline` on hover / focus。
- **改动**:`DemoCard.vue` 或 `style.css`。

#### P1-5 · 阶段 pill 颜色依赖单一通道
- **症状**:`.info-pill[data-phase="hold"]` 等 4 段颜色(#7af7d4 / #a8a3ff / #ff5c7c / #fbbf24)
  各自的对比比需要逐项验证。axe 暂未报,但 `--bg: #0a0a14` + pill 背景 `rgba(8,8,18,0.85)`
  上,#7af7d4 达 14:1 没问题;但 #fbbf24(amber) 在深色背景上 = 11:1,过。
- **命中**:`PlaygroundPage.vue` `.info-pill[data-phase=*]`。
- **修复**:无需改色,但加 pill 的 `aria-label="当前 phase: hold"`,键盘/屏幕阅读器明确阶段名。

#### P1-6 · `<pre>` 横向溢出无键盘访问
- **症状**(axe 1 处):DemoThemes `<pre class="code">` 横向滚动,但 tabindex 缺。
- **修复**:`<pre>` 加 `tabindex="0"`,样式不变。或者改用 `<pre style="white-space: pre-wrap; word-break: break-all">`
  避免滚动。后者影响代码可读性,选前者。
- **改动**:`DemoThemes.vue`(及所有 demo 页的 `<pre class="code">`)。

#### P1-7 · `tabindex` 顺序
- **症状**:Tab 顺序靠 DOM 顺序自然形成,目前合理(Brand → Nav Links → Toggle → Main → Footer),
  但 Playground 因为有 `aside` 在 canvas 之前,Tab 顺序是 aside 全跑完才到 canvas / code-output,
  在小屏 stacked 后顺序仍然 OK。
- **修复**:无。但加 `main` `tabindex="-1"` 配合 skip link 跳转。

#### P1-8 · 链接 hover 缺下划线
- **症状**:全局 `a { text-decoration: none }` + `a:hover { color: var(--accent) }` —
  鼠标用户 OK,但**对色觉障碍 / 弱视用户**缺少第二通道。
- **修复**:`a:hover, a:focus-visible { text-decoration: underline; text-decoration-thickness: 1px; text-underline-offset: 3px; }`。
  不影响视觉密度。
- **改动**:`style.css`。

## 9. 风险 / 取舍

1. **`prefers-reduced-motion`** 的全局 `transition-duration: 0.01ms` 会让 hover transition
   也消失,部分用户偏好"颜色淡入但不动"。改用
   `*:not(canvas) { animation: none; transition: none; }`,把 canvas 排除,
   同时不破坏 Hero 静态显示。已采纳此写法。
2. **heading-order** 的 P2-1:在 footer 内部把 `<h5>` 改成 `<h3>` 会破坏 footer 的视觉节奏
   (footer 的小标题故意小于主区)。权衡后保留 `<h5>`,接受 axe 报警,
   但在 main landmark 和 footer landmark 之间加注释说明。
3. **color-contrast 修 token 涉及** ~20 个文件。最稳的修法是改 `style.css` 里的 token,
   让所有 vue scoped 样式自动跟随。本次采用此法,token 升一档:
   `--text-faint: #3b3e54 → #6b6f8a`,`--text-dim: #5a5d75 → #7a7d95`,
   `.tk-com: #5a5d75 → #7a7d95`。
4. **axe 的 incomplete** 不计入 violations 总数,但浏览器扩展(Deque devtools)实测仍报。
   本轮以 violations < 10 为准,incomplete 列入 P2。
