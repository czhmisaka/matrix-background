## 3. 单条 console 警告:不是错误,无需处理

每张截图都伴随 1 条 `console.error`:

```
The Content Security Policy directive 'frame-ancestors' is ignored when
delivered via a <meta> element.
```

**性质**:浏览器提示,非应用错误。`frame-ancestors` 是 CSP 指令里**唯一**不支持 `<meta>` 标签的,
必须通过 HTTP 响应头设置才生效。`site/index.html` 里写的是:

```html
<meta http-equiv="Content-Security-Policy" content="...; frame-ancestors 'none'; ..." />
```

→ 浏览器忽略 `frame-ancestors` 部分、其余指令照常生效,出现一条 informational 提示。

**影响**:

- 当前是纯静态站,部署到 Cloudflare Pages 后会通过 `_headers` 文件
  (见 `site/dist/_headers`)用 HTTP 头下发完整 CSP,这条警告自然消失。
- 不影响截图、不影响 axe、不影响 npm test。
- 修法(可选):从 `<meta>` 里删掉 `frame-ancestors 'none';`,改在
  `site/public/_headers` 显式写 `Content-Security-Policy: ... frame-ancestors 'none'`,
  部署时由 CDN 加头。本轮**不修**,留作 deploy 期微调。

> 本报告把这条 console.error **标记为"已知良性"** 而非"异常",
> 因此 §2 表格没有标红,§1 汇总里"含 error: 0"。

## 6. 截图脚本工作流(`test/e2e-screenshots.mjs`)

```
┌─────────────────────────────────────────────────────────────┐
│  node test/e2e-screenshots.mjs                              │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
         1. rm -rf docs/e2e-2026-06-08/  (清空旧产物)
                            │
                            ▼
         2. spawn `npx vite preview --port 4173 --strictPort`
            cwd = site/
            wait for "Local: http://localhost:4173/"
                            │
                            ▼
         3. fetch http://localhost:4173/  探活(15s 超时)
                            │
                            ▼
         4. chromium.launch() headless
                            │
                            ▼
         5. for vp in [desktop 1440×900, mobile 375×812]
              for route in 12 路由:
                ├─ page.goto(url, { waitUntil: 'networkidle' })
                ├─ page.waitForTimeout(800)  ← canvas paint
                ├─ probe = evaluate(() => main/canvas/h1-h6/bodyH)
                ├─ page.screenshot({ fullPage: true })
                ├─ 收集 pageerror + console.error
                └─ 打印 + push 到 results
                            │
                            ▼
         6. writeFile report.json
            关闭 browser + kill preview 子进程
```

**关键设计**:

- **自起自停 server**:不需要外部 dev server,脚本跑完 SIGTERM preview 子进程。
- **`fullPage: true`**:截整页(不止 viewport),方便后续算 body 高度 / 长截图拼接。
- **`networkidle` + 800ms wait**:matrix-rain 是 canvas 动画,`networkidle` 触发后还有 RAF
  循环,800ms 足够画 1-2 帧。如果改 0ms,会截到空白 + 文字闪一下。
- **probe 字段**:把页面 DOM 关键计数 + main 文本截断都写到 `report.json`,这样后续脚本
  校验"是否真的渲染了内容"不需要再启浏览器。
- **filter 已知良性**:favicon / 资源 404 / `frame-ancestors` 警告不计入 errors(console
  error 还会记到 report,§3 解释),保留全部信息,但 `含 error` 统计可灵活判断。
