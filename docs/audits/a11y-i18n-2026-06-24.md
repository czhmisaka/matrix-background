### 1.2 键盘可达性

**现状**:

- 全站 `:focus-visible` 焦点环 + 2px 实色 outline(`site/src/style.css:145-158`)
- `<main id="main" tabindex="-1">` + `router.afterEach` 自动 focus + skip-link 到主内容(`site/src/App.vue:4` + `router.ts:51-56`)
- Tutorial 12 章节已有 `role="tablist"` / `role="tab"` / `@keydown="onTabKeydown"`(`TutorialPage.vue:13-36`)
- PlaygroundPage 7 个 range slider 全部带 `aria-valuemin/max/now/text`(`PlaygroundPage.vue:39-94`)
- Lock Order 按钮组 `role="group" aria-label="锁定顺序"` + `aria-pressed`(`PlaygroundPage.vue:155-167`)

**P1 缺失**:

- **P1-1**:Lock Order 7 个按钮(`random` / `topdown` / `bottomup` / `center` / `edge` / `leftright` / `rightleft`)**鼠标可点,但键盘只能用 Tab + Space 单选,无方向键快捷切换**。WCAG 2.1.1 + ARIA radiogroup pattern 应支持 左右方向键 切换。
- **P1-2**:Playground canvas 接收 `@pointermove` 实时显示坐标 readout(`PlaygroundPage.vue:189, 388-398`),**键盘用户(无鼠标)永远看不到 cell R:C readout**,因为 readout 是 `aria-hidden="true"`(`PlaygroundPage.vue:200-205`)。无键盘替代路径。
- **P1-3**:HeroCanvas **8s 自动涌现循环**(`HeroCanvas.vue:150`),仅 `prefers-reduced-motion` 守卫,**无 user-initiated pause**。WCAG 2.2.2 Pause, Stop, Hide 要求 > 5s 自动动画必须可暂停。

### 1.3 动画与前庭功能 (`prefers-reduced-motion`)

**已正确处理**:

- 全局样式 `@media (prefers-reduced-motion: reduce)` 抑制 keyframes + transform transition(`site/src/style.css:167-182`)
- HeroCanvas 循环 `if (!reduce) setInterval(regenerate, 8000)`(`HeroCanvas.vue:148-151`)
- README 显式标注 "无障碍:`prefers-reduced-motion` 自动停用"(L19)

**P2 缺失**:

- **P2-1**:PlaygroundPage 调参时 `setTarget(text)` 立即触发 noise -> converge 涌现,**无 reduced-motion 检查**(`PlaygroundPage.vue:402-404`)。即使全局 CSS 抑制 transform,canvas 本身的字符流(非 CSS 动画)仍每秒重绘 60 次,前庭敏感用户请求 reduce 后仍看到持续字符运动。
- **P2-2**:`.prompt-cursor { animation: blink 1s step-end infinite }`(`HeroCanvas.vue:319`)与 `.meta-dot { animation: pulse 2s ease-in-out infinite }`(`HeroCanvas.vue:372`)虽被全局 reduced-motion 抑制,**但全局抑制器只动 `animation-duration`,若 `animation-iteration-count: infinite` 不被覆盖,某些 Chromium 版本闪烁/脉冲仍持续**(已用 `animation-iteration-count: 1` 覆盖,需 axe-core 实测复核)。

### 1.7 Screen-reader 体验

**OK**:

- Theme switcher / Playground / ImageConverge / ChatLog / AITunePanel / HeroCanvas 均有 `role="status" aria-live="polite"` 状态播报
- TutorialPage 完整 tablist / tab / tabpanel(`TutorialPage.vue:13-36`)
- ImageConvergePage `<div role="progressbar" :aria-valuenow>`(`ImageConvergePage.vue:41-46`)
- ImageConvergePage 错误 banner `role="alert" aria-live="assertive"`(`ImageConvergePage.vue:31`)

## 6. 对发行版的影响

### 6.1 对 npm 包 `@xietuier/matrix-rain` 的影响

| 维度 | 影响                                                                                                                                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| a11y | **npm 包本体零影响**——它是 library,使用者在自己 app 里挂载 `<canvas>`,包不强制加 aria 属性。**但 README 章节 "无障碍"只提 reduced-motion,未提 canvas 必须 aria-hidden**,新用户复制示例到产品页会漏掉这个关键步骤。 |
| i18n | 零影响(包内 0 字符串)                                                                                                                                                                                              |
| SEO  | 零影响(包内无 HTML)                                                                                                                                                                                                |

### 6.2 对 demo 站 `matrix-rain.xietuier.ai` 的影响

| 维度                   | 现实风险                                                                                                                                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **a11y 投诉**          | **P0-1** AITune 页缺 aria-hidden -> 用户用 NVDA/JAWS 访问会听到 "graphic 1" 等垃圾播报。**这是会被 vite-plugin-axe / pa11y-ci 抓到的 critical 级别,GitHub Issue 风险高**。                                    |
| **Lighthouse a11y 分** | 当前 demo 站 Lighthouse a11y 跑分预估 95+ (2026-06-08 修了 144 violations),但 **P1-4 渐变按钮在 Lighthouse 中会被归类 incomplete / manual review**,会让分浮动。                                               |
| **社交分享**           | **P2-7** OG 缺失 -> 在 Twitter / LinkedIn / 微博 分享 https://matrix-rain.xietuier.ai 链接 **= 空白卡**,完全没有"canvas 动效 + 主题切换"的视觉钩子,**会显著降低 npm 引流转化**。                              |
| **SEO 收录**           | **P2-8** 无 sitemap -> Googlebot 14 路由需从首页链接外链,部分深层页(如 `/playground` 用客户端渲染)**可能几周才被索引**。SERP 上 0 rich result(GitHub / npm 那边的会显示,但**demo 站本身不会有 stars 显示**)。 |
| **i18n**               | **P2-6** 0 双语 -> **境外开发者访问 demo 站 = 看不懂**,npm 上 50% 用户在美国 + 欧洲,**等于放弃一半潜在客户**。GitHub trending 中文项目 -> 英文用户放弃。                                                      |
