## 1. 部署脚本

新增两条 npm script 到根 `package.json`:

```json
"deploy:local": "npm run build && node scripts/copy-site-assets.mjs && cd site && pnpm install --prefer-offline && pnpm type-check && pnpm build",
"deploy:serve": "cd site && pnpm preview --port 4173 --host 127.0.0.1"
```

**链路拆解**:

1. `npm run build` — tsup 打主包 + build-atlas 渲字符 atlas PNG/JSON + 拷 CSS + 拷字体
2. `node scripts/copy-site-assets.mjs` — dist/index.umd.js + matrix-rain.css 拷到 `site/public/matrix-rain/`
3. `cd site && pnpm install --prefer-offline` — site 子项目用 pnpm(独立 lockfile)
4. `pnpm type-check` — vue-tsc 检查 site/src Vue 组件
5. `pnpm build` — vite build 输出到 `site/dist/`
6. `pnpm preview` — 本地服务产物,验证 200

## 6. 已知限制

### 6.1 字体打包方式

字体 `jetbrains-mono.woff2` 走 `dist/fonts/` 路径,site 子项目需要另外 copy(目前 `scripts/copy-site-assets.mjs` 只拷 UMD+CSS,字体未自动拷)。如站点要展示 4 个变体字体效果,需手动 `cp dist/fonts/* site/public/matrix-rain/`。后续可在 copy-site-assets.mjs 加 fonts 路径。

### 6.2 端口冲突

`pnpm preview` 默认 4173 端口,如占用需手动 `--port 4183` 等。`deploy:serve` 脚本写死 4173,未来可加 `lsof -ti:4173 | xargs kill` 自检。

### 6.3 SPA 路由

`/demos` 等 SPA 路由通过 vite preview 的 history fallback 返回 index.html,正常。但若部署到带路由限制的静态托管(如某些 Pages 配置),需配 `_headers` 已在 `site/dist/_headers` 内由 vite-plugin 生成。
